# Front SENA

Vue 3 + Quasar + Pinia (+ persistedstate) + Vue Router + Axios + SweetAlert2.

```bash
npm install
npm run dev              # http://localhost:5173
npm run build            # genera dist/ para desplegar el front por separado
```

Antes: en el backend `npm run seed` y `npm run dev` (puerto 4500).
Acceso de prueba: `admin@sena.edu.co` / `123456`. La URL de la API está en `.env` (`VITE_API_URL`).
